# Modelo de procedência dos artefatos — Pokeidle Manager v0.1.0 RC4

> Este modelo não comprova a origem de binários. Preencha-o somente depois de
> gerar e congelar os artefatos finais aprovados. Não publique enquanto houver
> campos pendentes.

## Identificação da compilação

- Versão do produto: `0.1.0`.
- Tag planejada: `v0.1.0-rc.4` (ainda não criada).
- Branch de preparação: `release/v0.1.0-rc.4`.
- Commit exato usado na compilação: preencher com o SHA completo após a
  aprovação e o merge da preparação.
- Repositório de origem: `https://github.com/DiuleJR/pokeidle-manager`.
- Origem dos binários: compilação local a partir do código-fonte desse commit;
  não usar binários de outra instalação ou de terceiros.

## Ambiente e comandos

- Sistema operacional e arquitetura: preencher no ambiente real de compilação.
- Versões de Rust, Cargo, Node.js, npm e Tauri: registrar as versões efetivas.
- Comando da interface: `npm run check` e `npm run build`.
- Verificações Rust: `cargo fmt --check`, `cargo clippy --locked --all-targets`
  e `cargo test --locked`.
- Compilação comunitária para produção: `cargo build --release --locked
  --no-default-features --features community-build`.
- Empacotamento final, se aprovado: `npm run tauri:build:community`.
- Configuração Tauri: identifier `com.pokeidle.manager`; não usar o perfil
  `com.pokeidle.manager.smoke`.

## Artefatos finais e hashes

Preencha os nomes e os hashes SHA-256 depois de os arquivos finais estarem
congelados. Se qualquer binário mudar, gere novamente todos os hashes.

| Artefato | SHA-256 |
| --- | --- |
| Instalador Windows NSIS (`.exe`) | preencher após a compilação final |
| Instalador Windows MSI em português do Brasil (`.msi`) | preencher após a compilação final |
| `SHA256SUMS.txt` | gerar a partir dos instaladores finais |
| Notas da versão | `docs/releases/v0.1.0-rc.4-review.md` |
| Lista de verificação | `docs/releases/v0.1.0-rc.4-test-checklist.md` |

Não inclua caminhos locais pessoais. Registre somente metadados necessários
para reproduzir e conferir a procedência dos artefatos.
